# Sprint 1 체크리스트 — DB 설계와 기반 환경 구축

## 1. 스프린트 목표

인증·프로필·매칭 기능을 구현하기 전에 데이터 구조, API 계약, AWS·EOS 개발 환경을 확정하고 최소 통합 경로를 검증한다.

```text
클라이언트 또는 테스트 요청
→ API Gateway
→ 테스트 Lambda
→ DynamoDB 읽기·쓰기
→ CloudWatch 로그 확인
```
