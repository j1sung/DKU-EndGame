# 커밋 메시지 양식

```text
<영어 태그>: <한국어 작업 요약>

- <주요 변경 내용>
- <관련 변경 또는 변경 이유>
- <필요한 경우 실제 확인 결과·주의사항>
```

## 예시 — 기능 구현

```text
feat: 캐릭터 기울기와 균형 회복 구현

- 이동 입력에 따른 몸 기울기 누적과 입력 해제 후 회복 추가
- 최대 기울기 도달 시 넘어짐 처리 연결
- 관련 캐릭터 설정과 기능 설명 문서 갱신
```

## 예시 — 오류 수정

```text
fix: 방장 퇴장 후 참가자 연결 정리 수정

- 방 종료 알림 후 참가자의 세션 정리와 메뉴 복귀 처리
- 중복 퇴장 요청 제한 및 관련 문서 갱신
```

## 예시 — 관리 체계

```text
docs: 프로젝트 문서 구조와 AI 작업 지침 정리

- 카테고리 대표 문서와 상세 문서의 탐색 구조 구성
- 문서 갱신 절차와 작업자 추적 규칙 정리
```

태그는 주된 변경에 맞춰 선택. 본문은 보통 2~5개 항목. ✅·⚠️는 실제 확인 결과나 중요한 제한에만 선택적으로 사용하며, 실행하지 않은 검증을 성공으로 표시하지 않기. 예시의 내용은 실제 작업 결과가 아님.
