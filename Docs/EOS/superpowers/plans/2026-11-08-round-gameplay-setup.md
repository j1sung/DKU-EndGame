# 네 라운드 경기 준비 연결 계획

> 실행: `superpowers:executing-plans`로 현재 세션에서 구현한다. 일반 선택은 사용자 위임 범위에서 권장안으로 진행한다.

## 기준과 범위

다른 PC의 `8c50f59` 기록에서 네 맵의 ArenaSpawn 4개 적용·저장·재로딩 완료를 확인했다. Round1·2는 GameMode Override 없음, Round3·4는 테스트용 GameMode다. 현재 PC에서 그 에디터 검증을 재실행한 것은 아니다.

이번 단위는 실제 경기용 GameMode와 스폰 예약·미리 배치한 캐릭터의 중복 방지다. 기존 `ACFWaitingGameMode`의 점수·탈락·UI·대기 캐릭터를 재사용하고 별도 `ACFRoundGameMode`로 LAN 동작과 분리한다. 배치 캐릭터는 에디터 에셋에서 삭제하지 않고 `CFRoundSpawnPreview` 태그를 명시적으로 붙여 해당 GameMode의 서버 초기화 때만 제거한다. 이 태그가 없는 캐릭터를 임의로 지우지 않는다.

- 경기 정원/최소 인원 4, 라운드 기본값 4. 초기 Pawn도 ArenaSpawn 4개만 사용하며 접속자별 자리를 예약하고 Logout 때 반환한다.
- 기본 Pawn과 PlayerController는 기존 대기용 Blueprint를 재사용한다. 새 에셋·프레임워크는 추가하지 않는다.
- 에디터 설정 도구는 기존 스폰 위치 일치와 깨끗한 에디터를 검사하고 네 맵을 백업한 후 GameMode Override·네 캐릭터의 표식 태그·`net_load_on_client=false`만 변경한다. 서버 초기 삭제 전파에만 의존하지 않고 클라이언트 맵 로드에서도 미리보기를 제외한다. 위치·크기·회전·소유 설정을 바꾸지 않는다.
- 기존 클래스가 예상과 다르거나 부착 관계/소유가 있으면 중단한다. 실제 맵은 Unreal 설치 PC에서 적용해야 한다.
- EOS 세션·백엔드 시작 보고·자동 경기 시작·라운드별 맵 전환·점수의 월드 간 보존은 이번 단위 밖이다. 현재 단일 월드 4라운드 코드를 서로 다른 맵 경기 완성으로 표현하지 않는다.
