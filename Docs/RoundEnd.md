# 탈락 · 관전 · 라운드 종료

> 라운드 점수·결과 UI·1~4R 자동 진행은 [RoundProgression.md](RoundProgression.md)를 참고한다. 아래는 해당 기능 이전 단계의 구현 기록이다.

## 현재 흐름

대기 → 3초 카운트다운 → 경기 중 → 라운드 결과까지 연결되어 있다. 최대 4명, 최소 2명이며 기존 아레나에서 진행한다. 결과 화면에는 승자 또는 무승부를 표시한다. 점수 계산, 다음 라운드, 최종 결과와 같은 방 대기 복귀는 후속 범위다. 현재 결과 화면에서는 Esc → 방 나가기로 종료할 수 있다.

## 탈락 판정과 연출

- 기존 균형 실패 또는 서버의 `AChickenCharacter::StartKnockdown(Direction)` 요청이 탈락 진입점이다. HP/충돌 및 실제 피격 방향 계산은 아직 추가하지 않았다.
- 아레나 GameMode는 경기 중 생존자 목록에 있는 플레이어만 한 번 탈락 처리한다. 중복 요청이나 종료 후 요청은 거부한다.
- 공중에서 탈락하면 수평 이동을 중단하고 중력으로 착지한 뒤 기존 4방향 넘어짐을 재생한다.
- 제거 타이머는 요청 시점이 아닌 **착지 후 넘어짐 시작 시점**부터 센다. 기본 1.6초로 현재 1.4초 클립과 전환 시간을 확보한다.
- `BP_CF_ArenaGameMode` Class Defaults → CF / Match → Elimination Display Time에서 연출 유지 시간을 조정할 수 있다.
- 넘어진 캐릭터는 다른 Pawn을 막지 않으며, 서버에서 제거하면 모든 참가자의 화면에서도 사라진다. 탈락 후 캐릭터를 다시 생성하지 않는다.
- 독립 `Test_CF_Knockdown` 맵에서는 기존처럼 넘어짐 자세를 유지하고 R로 재생성한다. 아레나의 제거·승리 처리는 적용하지 않는다.

## 관전

- 탈락한 플레이어는 자신의 넘어짐을 본 다음 고정 관전 카메라로 전환한다. 링 밖 일반 걷기 캐릭터나 자유 비행 SpectatorPawn은 만들지 않는다.
- 기본 카메라는 ArenaSpawn 위치들의 중심을 기준으로 경기장을 비스듬히 내려다본다.
- 다른 레벨에서 구도를 직접 정하려면 CameraActor에 Actor Tag `ArenaSpectatorCamera`를 추가한다. 해당 카메라가 있으면 자동 카메라 대신 사용한다.
- 호스트도 탈락할 수 있으며, 탈락 후에도 리슨 서버와 참가자 연결은 유지된다. 관전 중에도 Esc → 방 나가기를 사용할 수 있다.

## 라운드 결과

- 서버가 탈락 및 경기 중 퇴장 후 생존자를 확인한다. 2명 이상이면 경기를 유지한다.
- 같은 프레임의 탈락 요청을 모아 다음 타이머 틱에 판정한다. 1명은 승리, 0명은 무승부다.
- GameState의 `Phase`, `RoundWinner`, `RoundWinnerName`, `bRoundDraw`를 공유한다. 승자 이름은 결과 스냅샷으로 보관하므로 승자가 퇴장해도 이미 결정한 결과를 바꾸지 않는다.
- 승자는 이동·기울기·차징·자동 점프가 중단된다. 공중이었다면 중력으로 착지한다.
- 마지막 탈락자의 착지·넘어짐·제거는 결과 상태에서도 끝까지 진행한다.
- 결과 확정 뒤 중복 종료, 임의 재시작 또는 추가 넘어짐으로 승자를 바꾸지 않는다.

## 직접 확인하기

1. C++를 빌드하고 메인 메뉴에서 호스트 1명과 참가자 2명으로 같은 방에 접속한다.
2. 호스트가 시작한 뒤 한 플레이어가 방향 키를 계속 눌러 균형을 잃게 한다.
3. 첫 탈락자가 넘어지고 사라진 뒤 관전으로 전환되는지, 나머지 2명은 계속 경기하는지 확인한다.
4. 두 번째 플레이어도 넘어지게 한다. 모두에게 남은 플레이어의 승자 표시가 나와야 한다.
5. 두 번째 탈락자의 넘어짐이 끝난 뒤 사라지는지, 승자의 조작·차징·자동 점프가 중단되는지 확인한다.
6. 호스트를 먼저 탈락시켜도 나머지 경기가 계속되는지 확인한다. 관전 중 Esc → 방 나가기를 누르면 참가자도 메뉴로 돌아온다.
7. 별도 경기에서 생존자가 2명일 때 한 참가자가 방을 나가면 남은 플레이어의 승리로 끝나는지 확인한다.
