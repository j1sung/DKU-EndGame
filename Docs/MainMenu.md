# 메인 메뉴 UI

2026-09-29. Unreal Engine 5.8.2에서 만든 첫 메뉴 화면입니다.

## 열어보기

1. 콘텐츠 브라우저에서 `Content/Maps/Lvl_CF_MainMenu`를 엽니다.
2. 상단 **Play**를 누릅니다. 이 레벨에는 배경용 3D 액터가 없어 편집 뷰포트는 검게 보이는 것이 정상입니다.
3. 닉네임 입력 → 참가하기 → 주소 입력 → 돌아가기를 확인합니다.
4. 종료 버튼은 PIE를 종료합니다. 게임 실행본에서는 게임을 종료합니다.

`Game Default Map`은 이 메뉴 레벨로 지정했습니다. `Editor Startup Map`과 기존 경기장 게임모드는 유지했습니다.

## 구성

| 에셋 | 역할 |
|---|---|
| `/Game/UI/MainMenu/WBP_CF_MainMenu` | 단색 배경, 닭싸움 제목, 닉네임, 방 만들기·참가하기·종료, 주소 입력 창, 상태 안내 |
| `/Game/UI/MainMenu/BP_CF_MenuController` | 로컬 플레이어에게 위젯 생성, Add to Viewport, UI Only 입력, 마우스 커서 표시 |
| `/Game/UI/MainMenu/BP_CF_MenuGameMode` | 메뉴 컨트롤러 지정, 경기 캐릭터와 HUD 생성 안 함 |
| `/Game/Maps/Lvl_CF_MainMenu` | 메뉴 전용 레벨, 메뉴 게임모드 Override |

위젯의 **Designer**에서 색·글자·배치를 수정할 수 있습니다. 중앙 앵커와 프로젝트 기본 DPI 스케일을 사용합니다. 배경 이미지나 외부 폰트, FBX를 추가하지 않았습니다.

참가 창이 열리면 뒤쪽 메뉴 입력을 비활성화하고 `AddressInput`에 포커스를 둡니다. 돌아가면 메뉴를 다시 활성화하고 `JoinButton`으로 포커스를 복원합니다.

## 현재 범위와 다음 연결

- **완료:** 입력 필드, 버튼 hover/pressed 스타일, 참가 창 열기·닫기, 상태 안내, 종료, 로컬 UI 생성.
- **아직 없음:** 실제 방 생성/접속, 닉네임 저장·전송·검증, 서버 검색, 경기장 이동, 대기실과 게임 매니저.
- `HostButton → OnClicked`는 현재 준비 중 안내만 표시합니다. 여기에 향후 GameInstance의 `HostGame`을 연결합니다.
- `ConnectButton → OnClicked`도 안내만 표시합니다. `NicknameInput`과 `AddressInput`을 읽고 검증한 뒤 GameInstance의 `JoinGame`으로 전달합니다.
- 다음 단계에서 진행 중 버튼 잠금, 접속 실패 안내, 닉네임 유지, 연결 성공 후 경기장 이동을 추가합니다.
- 한쪽 다리 이동·물리·충돌·애니메이션 코드는 이번 변경에 포함하지 않습니다.

에셋은 엔진 기본 클래스에만 의존하는 일반 블루프린트입니다. 생성에 사용한 임시 에디터 도구나 새 C++ 런타임 클래스 없이 열 수 있습니다.

## 확인한 동작

- 저장된 레벨을 별도 PIE에서 실행하여 메뉴가 한 번만 생성되는지, 커서 표시, 게임 Pawn 미생성, 한글 닉네임과 주소 입력, 참가 창 열기·닫기, 상태 안내를 자동 검증했습니다.
- 실제 에디터 Play에서도 한글 표시·입력, 버튼 클릭, 참가 창, 종료를 확인했습니다.
- 방 생성/클라이언트 접속은 구현하지 않았으므로 네트워크 테스트 결과가 아닙니다.
